#  KidKinder – Kids Learning Center Website

A responsive website for a kids' learning center, built with **HTML5** and **CSS3**.

## 📌 About

KidKinder is a static, multi-section landing page for a kindergarten / kids education center. It presents the school's facilities, classes, teachers, parent testimonials and blog articles, along with a seat booking form.

## ✨ Features

- Header with logo, navigation links and "Join Class" button
- Hero section with a call-to-action
- Facilities section (Play Ground, Music and Dance, Arts and Crafts, Safe Transportation, Healthy Food, Educational Tour)
- About us section
- Popular classes with age, seats, timing and fee details
- "Book A Seat" form
- Teachers section
- Parent testimonials
- Latest blog articles
- Footer with contact details, quick links and newsletter form
- Responsive layout for mobile and tablet screens

## 🛠️ Built With

- HTML5
- CSS3 (Flexbox and media queries)
- [Font Awesome 6.4](https://fontawesome.com/) for icons

## 🚀 How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Double-click `index.html` to open it in your browser.

An internet connection is needed to load the Font Awesome icons.

## 📱 Responsive Design

The layout switches to a single-column view on screens up to `768px` wide, so it works on phones and tablets as well as desktops.
